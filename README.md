# passport-reader

离线 Android 出入境证件读取器。项目处于早期开发阶段，不具有法定身份认证效力。

## 计划支持

- 往来港澳通行证：卡面资料及背面签注 OCR
- ICAO 电子护照：资料页/MRZ OCR、PACE/BAC、DG1/DG2/SOD
- 港澳居民来往内地通行证（回乡证）：卡面 OCR、实验性 ICAO LDS NFC
- 港澳居民来往内地通行证（非中国籍，HA/MA）：卡面 OCR、实验性 NFC
- 台湾居民来往大陆通行证（台胞证）：卡面 OCR、实验性 ICAO LDS NFC

## 隐私与安全

图片和识别结果仅在设备内存中处理，默认不保存、不上传，并禁止系统截取敏感页面缩略图。日志不得包含证件号码、姓名、出生日期、照片、MRZ 或芯片数据。

回乡证与台胞证的公开官方资料说明其为电子证件，但并未公开确认第三方应用可直接使用 ICAO 9303 BAC/PACE 读取个人资料。此项目只尝试标准、已授权的协议操作，不猜测密钥、不绕过访问控制、不读取指纹。实验结果不得用作真伪或身份认证结论。

## 构建

需要 JDK 17 和 Android SDK 35。仓库包含 Gradle 8.9 Wrapper；Windows 下运行 `gradlew.bat test assembleDebug`。

## 实卡测试

只使用持证人明确授权的香港/澳门回乡证及台胞证。测试记录仅保留脱敏后的协议阶段、Android NFC tech list、错误类别与耗时，不保留原始 APDU 或个人资料。
